# PocketWave · CodeAlpha Task 1

| Required feature | Working route or model |
| --- | --- |
| Listings | `/products/` with search, type and sort |
| Detail | `/products/<slug>/` with specs and stock |
| Cart | `/cart/` plus POST add/update/remove |
| Orders | `/checkout/`, `/orders/`, Order and OrderItem |
| Accounts | `/register/`, `/login/`, `/logout/` |
| Database | SQLite, Product and built-in Django User |

Use `python manage.py test` to verify the checkout flow. Demo checkout does not collect payment.
